# typeahead
A lightweight and responsive autocomplete search bar built using HTML, CSS, and JavaScript. This project provides a basic implementation of a typeahead component that dynamically suggests options as the user types into the input field.

🚧 Future Update: Integration with a live API is currently under development to provide real-time suggestions based on external data sources.

✨ Features
Simple and clean UI
Keyboard navigation support (up/down arrows + Enter key)
Matches suggestions in real-time as user types
Fully responsive design
Easy to customize and extend

🧰 Technologies Used
HTML5 – Markup structure
CSS3 – Styling and layout
Vanilla JavaScript – Core functionality
